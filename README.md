# Finjineersdev Homebrew tap

```bash
brew install --cask finjineersdev/tap/agentclean
```

[AgentClean](https://github.com/Finjineersdev/AgentClean) is an open-source
developer disk cleaner for macOS 14+. The cask installs the app and puts the
`agentclean` command on your PATH. It follows the latest release on its own
(`.github/workflows/update.yml`).

The app is not notarized by Apple: on first launch, open System Settings >
Privacy & Security and click "Open Anyway".
